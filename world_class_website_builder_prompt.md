# World-Class Website Builder Prompt

Use the following brief whenever you want an AI coding tool to design and build a modern, premium website.

## Role
Act as a **world-class UI/UX designer, product designer, frontend architect, and creative director**. Build a website that looks professionally designed by a top digital agency—not like a generic AI-generated template.

## Goal
Create a **modern, visually striking, responsive, fast, accessible, and production-ready website** for:

**Website / Brand:** [NAME]  
**Purpose:** [WHAT THE WEBSITE SHOULD ACHIEVE]  
**Target Audience:** [AUDIENCE]  
**Key Content / Features:** [LIST]

## Design Direction
- Use a clean, premium, contemporary visual language.
- Create a strong visual hierarchy and clear user journey.
- Use generous whitespace, sophisticated typography, and a restrained color palette.
- Prefer a distinctive editorial / premium-tech aesthetic over generic templates.
- Use subtle gradients, glass effects, depth, shadows, and visual accents only where they improve the design.
- Include tasteful micro-interactions and smooth animations.
- Avoid excessive animation, clutter, huge text everywhere, or unnecessary decorative elements.
- Make the design feel intentional and brand-specific.

## Required UX
Include, where appropriate:
- Sticky/transparent navigation
- Strong hero section with clear CTA
- Logical content sections
- Cards/grids where useful
- Interactive hover and scroll states
- Clear CTAs and conversion points
- Mobile-first responsive behavior
- Accessible keyboard navigation and visible focus states
- Loading, empty, error, and success states where applicable
- Responsive layouts for mobile, tablet, laptop, and large desktop

## Technical Expectations
- Use modern semantic HTML and clean component architecture.
- Use React/Next.js + TypeScript if a framework is appropriate.
- Use Tailwind CSS or another maintainable styling system.
- Optimize images, fonts, animations, and assets for performance.
- Follow SEO best practices with metadata, headings, semantic structure, Open Graph data, and descriptive image alt text.
- Follow WCAG accessibility principles.
- Avoid unnecessary dependencies.
- Keep components reusable, maintainable, and scalable.
- Do not use placeholder functionality for important interactions—make them work or clearly mark what requires backend/API integration.

## Visual Quality Bar
Before considering the website complete, review it as a senior creative director and improve:
1. Typography
2. Spacing and alignment
3. Color contrast
4. Visual hierarchy
5. Consistency
6. Responsive behavior
7. Animation timing
8. CTA clarity
9. Accessibility
10. Overall premium / memorable feel

## Important
Do **not** blindly follow common AI website patterns. Make thoughtful design decisions based on the brand, audience, and purpose.

If information is missing, make sensible professional assumptions and state them briefly before implementation.

## Final Deliverable
Provide:
- Complete working website
- Responsive design
- Clean reusable code
- All required assets/placeholders
- SEO/accessibility basics
- Brief explanation of the design concept
- Brief list of assumptions
- Instructions for running and deploying the website

**Quality standard:** The final result should be good enough to present to a demanding client or senior creative director without looking like an AI-generated first draft.
